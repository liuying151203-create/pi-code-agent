# 从零实现可扩展 Agent

新主线每章都交付可运行示例、正式接口和测试。先完成核心组件，再通过扩展实现具体功能；SDK 不单独开章。

每章目录保存当时的完整循环和所需组件，仅在本章内部相对导入，不引用产品源码或其他章节。后续产品升级只改 `src/` 和新章，旧章保持原有阶段；测试分别检查各阶段行为。冻结清单及 Python、外部库的验证版本见 [snapshots.json](snapshots.json)。只复制某章目录也能以 Python 包运行，外部库仍使用对应的环境。

学习时使用该章自己的消息、工具和模型类型；正式开发使用 `pi_code_agent`。两套对象不要混用。旧章发现 Bug 时明确修订、补回归测试并更新清单，不自动用最新源码覆盖。

7. [s07：扩展加载与工具注册](s07_extensions/README.md)：可信工厂事务、注册优先级和来源进入实际会话
