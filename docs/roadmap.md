# 新主线安排

已完成：s01 异步核心循环，s02 工具契约与参数校验，s03 统一模型接口，s04 运行事件与订阅。SDK 和终端入口随功能交付，没有独立的 SDK 包装章节。

下一步完成 s05 流式响应：从供应商流接收增量，通过 message_update 事件交给界面，同时保存完整回答。之后按依赖推进会话与状态、扩展注册与拦截、命令和参数、取消与消息队列、会话切换与分支、压缩和恢复、资源加载、动态能力与交互适配；后续具体章节编号待定。

旧章节按能力迁移，不直接按数字平移：旧 s16 的接口内容并入对应功能，旧 s03 审批与 s15 Todo 归入扩展实践，旧 s13 A/B/C 归入可替换执行后端专题。会话、Skills、模板等只讲一次；新功能先对齐锁定版本的 Pi，再讨论 Python 生态或产品边界差异。

新核心当前支持文本消息、顺序工具调用、Pydantic 参数校验、显式模型配置、两种完整响应协议，以及八种运行事件和有序等待订阅。流式、会话、并行、重载、MCP 和 TUI 尚未在新主线实现。旧版已经具备的部分保存在归档中，后续逐项核对、迁移；归档没有的能力仍需新建。
